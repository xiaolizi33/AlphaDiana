题目 `test/algebra/2251.json`，来自 G 集。案例在运行完成后按明确规则选择，用于查看层间传递。

If $\sqrt{3x-5}=2$, find all possible values of $x$.

|策略层数|输出|正确|实际预处理顺序|
|---:|---|---|---|
|0|3|True||
|1|x = 3|True|2|
|2|3|True|3 → 2|
|3|3|True|4 → 3 → 2|
|4|3|True|5 → 4 → 3 → 2|
|5|3|True|6 → 5 → 4 → 3 → 2|
|6|3|True|7 → 6 → 5 → 4 → 3 → 2|
